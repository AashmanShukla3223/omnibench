# OmniBench 1.0 — Universal Computer Use Model Demo

OmniBench 1.0 runs a local 100M parameter vision-language model ONNX engine under ~1.1 GiB RAM on CPU.
It generates precise computer use action primitives (`click`, `double_click`, `right_click`, `drag`, `type`, `call_contact`).
